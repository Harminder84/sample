Privacy Policy

Effective date: 2 November 2026

Property Classifier is a personal application used by its owner to classify and organise property-related email messages.

Information accessed

When authorised, the application accesses Gmail messages and related metadata needed to identify property correspondence, actions, dates and reminders.

Use of information

Information is used only to classify property messages and produce reminders and reports for the account owner.

Sharing

Google user data is not sold, used for advertising, or shared with unrelated third parties.

Storage and deletion

Processed information is retained only as needed for the owner's property workflow. Access can be revoked through the Google Account permissions page.

Google API data

The application's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.
